# ADR-0004. Топологія розгортання навчального стенда

## Контекст

Потрібно відтворити створення поїздки й обробку події з ЛР5 на іншому комп’ютері. Шина та сховище працюють у пам’яті процесу. Контейнер повинен запускати той самий код.

## Варіанти

1. Запуск через dotnet на комп’ютері. Потрібне встановлене середовище .NET. Це зручно для розробки.
2. Один контейнер backend-api. Версію середовища визначає образ .NET, а порти й налаштування задає Compose.
3. API, брокер та окремі процеси споживачів. Їх можна масштабувати окремо, але знадобляться сховище ідентифікаторів, мережевий обмін і налаштування брокера.

## Рішення

Для демонстрації використати один контейнер backend-api із двома фоновими споживачами. На комп’ютері доступно HTTP на 8080 і gRPC через HTTP/2 на 8081. Прив’язка до 127.0.0.1 обмежує доступ до стенда поточним комп’ютером.

## Наслідки

Стенд легко відтворити, у нього один процес застосунку та єдиний журнал. Дані й черги зникають після зупинки контейнера. Щоб окремо масштабувати споживачів, потрібно винести транспорт у брокер і зберігати оброблені ідентифікатори за межами процесу.
